A minimal TypeScript template for a canvas app for the Coding Lab.

## Prerequisites

This project requires [Node.js and npm](https://nodejs.org/) to be installed on your machine.

## Installation

```bash
npm install
```

## Running Locally

**Development mode:**
```bash
npm run dev
```

**Build for production:**
```bash
npm run build
```

**Preview production build:**
```bash
npm run preview
```

Open your browser and navigate to the development server URL shown in the command line.
